# Design context (from the owner's brief, Nov 2026)

- **Audience:** Amaya by Vera Vita's sales team — agents (RMs) working enquiries all day on desktop and phone;
  sales managers watching exceptions and approving; founders / view-only users reading the business; a company
  admin setting up the team and connectors. Enquirers are often adult children abroad buying for parents.
- **Jobs:** enquiry → assigned agent → meaningful follow-up → family consultation → site / virtual visit →
  shortlist → quotation → reservation → booking → post-sales handoff.
- **Tone:** a calm, clear, fast daily work tool. Readable data and obvious next actions. No decorative dashboards,
  excessive cards, gratuitous gradients or template styling. Restrained motion only to explain state.
- **Identity to keep:** Jost; navy #0B2A44 ink, blue #0B6BB0 accent, sage #0E8A86, rust #B06A55, warm page
  #F4F0EB, white surfaces with #D3E3F0 lines (src/components/ui.tsx). The public booking page uses Amaya's warmer
  bronze (#A9825A) — kept for customer-facing pages only.
- **Accessibility:** keyboard reachable, visible focus, AA contrast, meaningful labels, 44 px touch targets on mobile.
